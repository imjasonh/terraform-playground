# Fixture provenance

These are the Wolfenstein 3D **shareware** episode files: the `*.WL1` data
files plus `wolf3d.exe` (shareware v1.4). The shareware episode was released
by id Software/Apogee for free distribution ("you are encouraged to share
this episode"), and these exact files are widely redistributed (data files
mirrored from the `ccie18473/wolf4rust` repository, the executable from
`mshoger/wolf3d`, both of which vendor the installed shareware release).
The EXE lets the editor's in-browser playtest run the demo out of the box.

They are used only as golden-test fixtures for the format codecs and as an
optional demo dataset for the editor. The registered episodes (`*.WL6`) and
Spear of Destiny data are NOT included and must be supplied by the user.
